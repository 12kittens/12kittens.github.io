A JS chess library for both Node.js and browser applications

HTML

                                
                            <chess-ui template="modern-light" src="./test.pgn" playerbar>
                            </chess-ui>

Bishops.js is a modern JavaScript chess library including logics, PGN parsing and a simple HTML-based user interface, intended for web applications and Node.js projects, inspired by niklasf's python-chess library.

This project is still under development.

Features

  • Includes JSDoc annotations
  • Agnostic Web Component-based UI, inspired on images
    • HTML
    
                            <chess-ui src="./test.pgn" width="700" height="450">
                            </chess-ui>
    JavaScript
    
                        import { ChessUI } from 'bishops/ui'

                        const ui = new ChessUI()
                        ui.src = './test.pgn'

                        document.body.appendChild(ui)
  • Make moves from UCI and SAN strings
    • JavaScript
    

                        import { Game } from 'bishops/core'

                        const game = new Game()

                        game.move('e4')
                        game.move('e7e5')
                        game.move('Nf3')

                        game.undo()
  • ASCII board rendering
    • JavaScript
    

                        game.position.print()

  • Checkmate, stalemate, dead position detection
    • JavaScript
    
                        console.log(game.position.isCheck)
                        console.log(game.position.isCheckmate)
                        console.log(game.position.isStalemate)
                        console.log(game.position.isGameOver)
                        console.log(game.position.isDeadPosition)
  • Detects threefold repetition and fifty-move rule
    • JavaScript
    
                        console.log(game.canClaimThreefoldRepetition)
                        console.log(game.canClaimFiftyMoves)

                        console.log(game.position.halfMoveCount)
                        console.log(game.mainBranch.repetitionCount)
  • Detects fivefold repetition and seventyfive-move rule (rules 9.6a and 9.6b, since 2014)
    • JavaScript
    
                        console.log(game.isFivefoldRepetition)
                        console.log(game.isSeventyfiveMoves)
  • Detects attacks
    • JavaScript
    
                        const threats = game.position.threats('f2', WHITE)
                        for(const threat of threats) {
                            console.log(nts(threat), game.position.pieceAt(threat))
                        }
  • Parse and create FEN strings
    • JavaScript
    
                        const game = new Game()
                        game.begin('rnbqk2r/pppp1ppp/5n2/2b1p3/2B1P3/5N2/PPPP1PPP/RNBQK2R w KQkq - 0 1')
                        console.log(game.position.fen)
  • Recursive variant (PGN-like) support
    • JavaScript
    
                        const branch = game.createBranchAt(idx(5, WHITE))
                        game.useBranch(branch)
                        game.move('5. Nc3')
                        game.useBranch(game.mainBranch)
                        game.move('5. c3')
  • Reads and writes PGNs from strings
    • JavaScript
    
                        const pgn = `
                        [Event "IBM Man vs Machine"]
                        [Site "New York, USA"]
                        [Date "1997.05.11"]
                        [Round "6"]
                        [White "Deep Blue"]
                        [Black "Garry Kasparov"]
                        [Result "1-0"]
                        [ECO "B17"]

                        1.e4 c6 2.d4 d5 3.Nc3 dxe4 4.Nxe4 Nd7 5.Ng5 Ngf6 6.Bd3 e6 7.N1f3 h6
                        8.Nxe6 Qe7 9.O-O fxe6 10.Bg6+ Kd8 11.Bf4 b5 12.a4 Bb7 13.Re1 Nd5
                        14.Bg3 Kc8 15.axb5 cxb5 16.Qd3 Bc6 17.Bf5 exf5 18.Rxe7 Bxe7 19.c4 1-0
                        ` 
                        game.pgn.import(pgn)
                        console.log(game.whiteName)
                        console.log(game.date)
                        console.log(game.pgn.export())
