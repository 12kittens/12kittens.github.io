A JS chess library for both Node.js and browser applications

HTML

                                
                            <chess-ui template="modern-light" src="./test.pgn" playerbar>
                            </chess-ui>

Bishops.js is a modern JavaScript chess library including logics, PGN parsing and a simple HTML-based user interface, intended for web applications and Node.js projects, inspired by niklasf's python-chess library.

This project is still under development.

Features

  • Includes JSDoc annotations
  • Agnostic Web Component-based UI
  • Make moves from UCI and SAN strings
    • JavaScript
    

                        import { Game } from 'bishops/core'

                        const game = new Game()

                        game.move('e4')
                        game.move('e5')
                        game.move('Nf3')

                        game.undo()
  • ASCII board rendering
    • JavaScript
